# Prompt for Claude Design (or any design agent)

Attach this repo (or just this folder) and paste everything below the line.

---

You're exploring visual variants for my personal site, noahairmet.com. The
site is already built and shipped — a small Astro static site (home,
writing, 404) whose whole visual system lives in
`src/styles/site.css`. I want design exploration on top of the existing
structure and content, not a rebuild.

Read `design-kit/CONTEXT.md` first: it holds the brief, the complete
copy, and the hard constraints. The short version: the direction is "one
ink" (a single blue-black on cool white, with one exhibit: a chart of
Pulpit's catalog), no invented claims, and the site must stay
zero-JavaScript, fully self-hosted under a strict CSP, with one motion
moment and nothing looping.

Give me 2–3 distinct visual variants of the home page and one post page.
For each: what changed, why it still reads as an honest early-career
security engineer, and the tradeoff versus the current design. Worth
exploring: the hero's use of width on desktop, the chart's size and
annotation, the serif/sans balance, the footer. I care about restraint and
precision, not more decoration.
