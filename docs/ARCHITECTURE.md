# Architecture

## Shape

A static Astro site with four kinds of page:

- `/` — home: masthead, three-sentence bio, recent field notes, links,
  Pulpit one-liner, colophon.
- `/field-notes/` — chronological index of all notes.
- `/field-notes/<slug>/` — one note per markdown file in
  `src/content/field-notes/`, rendered through the shared prose styles.
- `/404` — "Off the map."

Plus `rss.xml`, `sitemap-index.xml` (via `@astrojs/sitemap`), `robots.txt`,
the résumé PDF, and the unlinked `/bee` PWA (see `BEE-APP.md`).

## Rules the structure encodes

- **Content collections drive everything.** A new post is one markdown
  file; numbering (001, 002, …) is computed from date order at build time
  in `src/lib/site.ts`. Nothing else needs touching.
- **Zero client-side JavaScript.** The contour animation is CSS
  (`stroke-dashoffset` with `pathLength="1"`). If a future feature seems
  to need JS, it goes through Noah first.
- **CSP is the constraint, not a suggestion.** `public/_headers` sets
  `default-src 'self'` with no `unsafe-inline`. Consequences:
  - `astro.config.mjs` sets `build.inlineStylesheets: "never"`.
  - Fonts are npm-installed Fontsource packages, bundled into `_astro/`.
  - No external images, scripts, embeds, or analytics can ever be added
    without loosening the CSP — which is a Noah decision.
- **The artwork is data, not drawings.** `src/lib/contours.ts` is
  generated by `scripts/generate-contours.mjs` (deterministic seeds).
  Regenerate and re-embed rather than hand-editing paths.

## Build pipeline

`npm run verify` = `astro check` (strict TS) → `astro build` → node smoke
tests over `dist/` (`test/smoke.test.mjs`). The smoke tests assert the
contract: every route exists, styles stay external, fonts stay
same-origin, corpus stays unreachable, the resume redirect cannot loop,
security headers survive, RSS carries the notes, and no internal link is
broken. Deployment is Workers Static Assets from `dist` (`wrangler.jsonc`);
`_headers` and `_redirects` ship as assets and are honored at the edge.
